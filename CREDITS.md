# Credits

- **Smithay** (MIT licence), `src/backend/winit/mod.rs` in version 0.7.0: the order of steps that sets up OpenGL ES on a winit window under X11 and Wayland, followed by the display host's own window layer (`prototypes/spikes/display-host/src/window.rs`, removed with the prototypes and kept at the tag `prototypes-final`). The display host needs its own because Smithay's winit back end does not pass on input method events.
- **fullPage.js** (GNU General Public License version 3; the idea only, no code taken), its `MouseWheelHandler` in version 3.1.2: a mouse wheel counted by direction only, one step per wheel movement, ignored until the step's animation has finished. It solved single wheel notches being ignored while zoomed, because macOS reports a slow notch as a tenth of a line (`native/interface-core/src/wall.rs`, `Wall::wheel_notch`).
- **Noto** (SIL Open Font License 1.1), by the Noto Project Authors and Google LLC, as the engine converts it into "Noto Teletext", its 12 by 20 teletext font (the engine's `third_party/noto/`): the font of every page, compiled into the decoder with the engine (licence in `native/decoder/NotoTeletext-OFL.txt`).
- **music-synthesizer-for-android** (Apache License 2.0), by Google Inc. and Raph Levien, at commit `f67d41d`: how a Yamaha DX7 turns a patch's settings into sound over time, its envelopes, pitch envelope, LFO, scaling and operator frequencies, measured from the instrument. The engine carries them translated to Rust in its crate `neoteletext-audio-instruments` (`src/dx7/msfa/`, each file with its notice; the licence's text beside the crate as `LICENSE-APACHE-2.0`), and the browser's decoder process plays DX7 sounds with them (REQ-6415; the engine's DEC-6420). The sound kernel and the rack beside them are the engine's own.
- **mos6581** (MIT or Apache License 2.0; its documentation only, no code taken), by Enzo Lombardi, version 0.3.0: its record of which public document supports which fact about the SID chip, read as a reading list for the engine's own SID emulator, which the decoder process plays SID sounds with (REQ-6415; the engine's DEC-6418).
- **dx7** (MIT licence; no code taken), by Tyler Neely, version 0.0.4, a port of the FM engine of **Plaits** (MIT licence), by Emilie Gillet: a second reading of the DX7's packed patch layout and of the routing of its 32 algorithms, against which the engine's own were checked (the engine's DEC-6410).
